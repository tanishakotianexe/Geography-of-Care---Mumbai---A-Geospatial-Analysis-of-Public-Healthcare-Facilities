**Geography of Care – Mumbai**



**About the Project**

Geography of Care – Mumbai is a geospatial project that explores the distribution of public healthcare facilities and their relationship with population across nine BMC wards in Mumbai City.



The project uses interactive maps to make healthcare locations and ward-level geographic information easier to explore.


To open this project, downlaod the Geography Of Care - Mumbai file and open it in your local system.


**Objectives**

\- Map the locations of public hospitals and healthcare facilities.

\- Explore the distribution of UPHCs and dispensaries.

\- Visualise selected BMC ward boundaries.

\- Explore population and healthcare distribution using available data.



**Tools Used**

\- Kepler.gl – Interactive geospatial maps

\- Google Colab – Data cleaning and processing

\- GeoJSON.io – Ward boundary inspection

\- KML, CSV and SHP files – Geographic data formats

\- HTML – Interactive project presentation



**Project Structure**

\- `3d models/` – 3D assets

\- `csv maps/` – CSV datasets and related map files

\- `kml maps/` – KML geographic files

\- `shp file of greater mumbai ward wise/` – Ward boundary shapefiles

\- `visualization maps made using kepler/` – Maps created using Kepler.gl

\- `resources.txt` – Data sources and tools

\- `The Geography Of Care - Mumbai.html` – Interactive project page



**Notes**

The analysis focuses on nine selected BMC wards: A, B, C, D, E, F/N, F/S, G/N and G/S.



The coverage and reporting year of each dataset should be checked before drawing conclusions. Greater Mumbai-wide statistics should not be treated as statistics for these nine wards.
